neboc emit-asm

Lower a checked source file to assembly.

Identity: cli:emit-asm (CLI_FORM)
Edition: 1
Target: x86_64-systemv-elf-linux
Availability: EDITION_1_BOUNDED

Syntax or signature

neboc emit-asm source.no -o output [--edition 1|2] [--no-prelude]

Behavior and usage

Writes assembly to the explicit -o path after parser and semantic validation. Generated code still needs assembly/linking and execution.

Exit codes and remediation

Exit 0 means this command completed its stated operation; source errors use 1, invalid usage or environment uses 2, and an internal failure uses 101. An emitted file is not runtime proof. Correct the diagnostic and retry; never execute a rejected or partially published artifact.

Example commands

neboc emit-asm examples/rf204/G185/RF204-G185-S07.no -o build/nebo-example.asm
