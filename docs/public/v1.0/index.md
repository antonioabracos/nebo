# Nebo 1.0 public documentation

This offline-first documentation covers the Edition 1.0 language, core,
prelude, Standard Library, factual domain-pack maturity, tutorials and
troubleshooting.

Read the [individual core, language and prelude reference](core-reference.html)
for syntax, types, operators, implicit imports and essential diagnostics/CLI.

Browse the [individual Standard Library reference](reference/stdlib/index.html)
for module imports, stable members, bounded material profiles and target caveats.

- [Domain packs and advanced references](reference/domains/index.html)

Open the [offline learning portal and search](index.html), follow the
[clean-root installation tutorial](tutorials/getting-started.html), or browse
the [eight cookbook tasks](cookbook/index.html). The self-contained local
[documentation archive](offline-site/nebo-docs-v1.0.tar) includes the same
reference, projects, search, CLI manual and editor help.
