ForegroundColor

The intrinsic foreground-color behavior identity.

Identity: type:ForegroundColor (INTRINSIC_TYPE)
Edition: 1
Target: x86_64-systemv-elf-linux
Availability: EDITION_1_BOUNDED_NATIVE_AND_SOURCE_PROFILE

Syntax or signature

ForegroundColor
Native TypeId: 8 (not SymbolId)

Logical layout

A typed Console role descriptor, not an arbitrary user-definable behavior implementation.

Construction and members

Use Console.fg with an admitted Color or channel profile; a bare Color is not a Console option.

Protocols and ownership

The behavior retains the Color receiver type. Applying a foreground option changes the selected Console node; it does not mutate global output state or grant an additional capability.

Errors, limits and target

Use x86_64 Linux System V ELF for the executed examples. Incompatible types reject before publication; bounds and ownership checks precede an invalid read, mutation or drop. Internal descriptor layouts are not portable ABI promises.
