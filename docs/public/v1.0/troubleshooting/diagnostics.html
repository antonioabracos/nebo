Read a diagnostic before changing source

NEBO_CALL_UNDEFINED: check the current receiver and method signature. NEBO_TYPE_MISMATCH: inspect operand, argument and return types. NEBO-RF166-G163-004: add the documented explicit import. Source locations use UTF-8 byte spans; they identify the causal token.

Check, emit and build must reject malformed source before writing an artifact. Keep a small reproducer, then retest with an independent expected result. Current diagnostics are listed in the complete local diagnostic reference.
