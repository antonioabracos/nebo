# Known limits and maturity

Imports grant visibility, never capability. Experimental, bounded, target-gated, excluded and external-review APIs keep their classifications. The native one-worker task profile is not an unbounded parallel scheduler. Plain/headless Console is distinct from a live window.

No public Internet, external credentials, devices, accelerators or cryptographic certification is required or claimed. The domain reference lists each gate. Migration does not silently rewrite Edition 1 into Edition 2 or make a historical .ni interface compatible.
