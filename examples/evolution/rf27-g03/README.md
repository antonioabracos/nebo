# RF27-G03 bounded functions and modules

These single-unit examples exercise bounded receiver-first parameters and
defaults, deterministic constrained overload selection, and a statically
lowered callback. The multi-unit module/object/cache corpus lives under
`tests/rf27-g03/f05` and `tests/rf27-g03/f06`.

Dynamic linking, package-manager resolution, JIT compilation, variadics and
unbounded closure environments are outside this profile.
