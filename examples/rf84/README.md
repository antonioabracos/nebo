# RF84 bounded public example

`hello-console.no` uses the canonical zero-data-argument `console()` spelling already accepted by `neboc`.

The O2 FormatPlan A/B engines and the O6 equivalence proof are native Assembly APIs. The current compiler does not expose `.format(...)` or semantic `${...}` interpolation as public source syntax; examples must not imply otherwise. `.print()` and positional data arguments to `console()` remain rejected.
