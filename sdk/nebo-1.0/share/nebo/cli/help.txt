Commands:
  bench       Run the bounded local numeric benchmark.
  probabilistic-report  Inspect a redacted versioned probabilistic artifact.
  reactive-report  Analyze a bounded local reactive dependency graph.
  db          Verify or dry-run a compatible local database migration.
  firmware    Build or test the bounded simulator-only reference image.
  simulation-replay  Validate and replay a bounded versioned simulation log.
  crypto-audit  Inspect crypto metadata without reading secret bytes.
  optimize-explain  Report bounded optimization facts.
  bootstrap   Verify factual stage0 and source-compiler availability.
  toolchain-report/self-contained-audit  Report factual external dependencies.
  assemble/object-build/object-verify/link  Use the bounded internal ELF profile.
  reproducibility-report  Compare local build bytes without hidden normalization.
  diverse-build/trust-manifest/provenance-verify  Report bootstrap trust honestly.
  sdk         Pack, verify, restore and self-test a deterministic offline SDK.
  protocol    Generate bounded typed protocol artifacts.
  geometry-check  Validate bounded local geometry metadata and syntax.
  route-bench  Validate a versioned bounded local routing suite.
  emit-wasm/wasm-inspect  Emit or inspect a deterministic Wasm envelope.
  emit-bpf  Emit the verified two-instruction local eBPF subset.
  portable-test/portable-sbom  Validate or describe a local portable artifact.
  warnings    List the stable warning groups and defaults.
  explain     Show a versioned diagnostic explanation from the offline catalog.
  format      Canonically format compiler-admitted Nebo sources.
  lint        Run bounded source-style rules and preview safe fixes.
  repl        Evaluate Nebo sources in a bounded local session.
  init/add/remove/resolve/vendor/package/audit  Manage deterministic offline packages.
  lsp         Serve bounded JSON-RPC language features over stdio.
  completion-debug/completion-corpus  Inspect or verify revision-bound completion.
  hover/signature-help/definition/references/rename  Navigate or refactor by SymbolId.
  prelude-report/migrate-imports/stdlib  Inspect or migrate edition-owned SDK visibility.
  profile     Emit a deterministic local compiler/source profile.
  emit-hir/emit-lir  Inspect normalized compiler-admitted source IR.
  test/conformance/fuzz  Run fixed local test and conformance plans.
  abi-report/runtime-report  Inspect the versioned native compatibility boundary.
  compatibility-report/migrate  Inspect editions and bounded mechanical migration.
  conformance-manifest/doctor/security-report  Audit local release inputs.
  release/examples/nebo-1.0-readiness  Exercise local dry-run readiness without publication.
  api-diff    Compare semantic public API baselines.
  fix         Preview or atomically apply snapshot-bound fixes.
  refactor    Prepare identity-resolved semantic refactorings.
  source-optimize/modernize  Run explicit source transformations.
  change-review  Verify bounded before/after source equivalence.
  timings/compiler-profile/compiler-report  Inspect bounded compiler metrics.
  compiler-memory  Inspect bounded arena, interning, and pressure facts.
  incremental-report/query-report  Inspect cold-equivalent reuse facts.
  cache       Operate the bounded local content-addressed cache.
  serve/server  Operate the optional bounded local compiler service.
  project-report  Inspect bounded project scalability and pressure.
  compiler-bench/performance-gate  Evaluate reproducible local budgets.
  diagnostics Search the bounded offline diagnostic catalog.
  bug-report  Create or inspect a redacted local ICE bundle.
  minimize-ice  Emit a bounded local ICE reproducer summary.
  exit-codes  List the stable public process exit contract.
  meta-check   Validate a bounded typed metaprogram.
  meta-expand  Emit its normalized generated assembly to stdout.
  verify       Verify bounded contracts or emit a reproducible counterexample.
  solve        Execute a bounded local model and emit a structured report.
  check       Validate source without invoking the toolchain.
  emit-asm    Emit deterministic NASM Intel assembly.
  build       Produce a native ELF64 executable.

  module-check  Validate a bounded module graph without linking.
  module-info   Explain one module from the authenticated graph snapshot.
  module-graph  Render that snapshot as deterministic text, JSON, or DOT.
  imports       List, explain, or inspect public API impact.
  organize-imports/add-import  Apply explicit snapshot-bound import edits.
  module-init-report  Report the authenticated bounded startup plan.
  emit-interface  Emit a deterministic bounded compiled interface.
  interface      Inspect a native-validated compiled interface.
  symbols        Query the revision-bound project symbol index.
  symbol-index   Rebuild or verify the incremental local index.
  api-diff       Classify source, ABI and behavior compatibility.
  emit-object   Produce one deterministic relocatable ELF64 object.
  link          Compile and statically link a bounded three-unit module graph.

Target: x86_64-systemv-elf-linux
