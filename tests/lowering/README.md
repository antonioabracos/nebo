# MF030 lowering tests

The MF030 executable covers three primary Pending contracts and six infrastructure
scenarios:

- transitive cancellation propagation;
- controlled duplicate resolution;
- orphan Pending rejection at exit;
- deterministic continuation identity and naming;
- minimal captures;
- canonical Console/scan operation sequence;
- target-independent Function Lowering Plans;
- deterministic dump/golden;
- TR06 exit-gate state.
