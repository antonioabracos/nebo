# MF021 NAME tests

`mf021_name_test.asm` provides eight native Assembly scenarios owned by MF021:

1. binding visible after declaration;
2. use before declaration rejected;
3. duplicate in one scope rejected;
4. inner shadowing rejected;
5. function declared later resolved;
6. reserved declaration name rejected;
7. receiver and parameter symbols resolved;
8. deterministic ScopeIds, SymbolIds, side tables and hash.
