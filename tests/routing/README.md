# MF027 routing tests

The native test covers the nine primary ROUTE contracts:

1. default console;
2. named independent console;
3. scan on the default console;
4. scan on a named console;
5. anonymous console+scan chain;
6. independent named identities;
7. independent anonymous identities;
8. deterministic IDs, hashes and canonical dump;
9. complete compile-time metadata attached to the SemanticDatabase.

Negative routing diagnostics and invalid terminal forms remain MF028.
